# Projeto-Material-tecinfo

**Nome do Projeto:** Sistema de Gestão de Materiais de Construção

**Autor:** [Seu nome]

**Descrição:** O projeto consiste no desenvolvimento de um sistema para gerenciamento de materiais de construção, permitindo cadastrar, listar, editar e excluir produtos e clientes, incluindo informações de estoque e endereços para entrega.

**Tecnologias utilizadas:**
- React
- TypeScript
- Vite
- React Router DOM
- json-server
- HTML e CSS

**Objetivo:** Desenvolver uma aplicação web aplicando conceitos de desenvolvimento front-end, organização de componentes, rotas, tipagem com TypeScript e integração com uma API REST simulada, facilitando o gerenciamento de produtos e clientes.

**Como funciona?:** Vá em terminal, digite npm run dev e npm run api para o projeto funcionar.
